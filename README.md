## FAQ

### What is XCutors?

XCutors is a curated collection of popular Windows-based Roblox script executors bundled with a universal loader called xcutorsLoader, designed to simplify managing and running Lua scripts.

### Which executors are included?

The collection includes Volt, Synapse Z, Potassium, and Wave — all popular Roblox script executors — along with the xcutorsLoader universal management tool.

### What are the system requirements?

A Windows 10 or Windows 11 PC with at least 4 GB of RAM, .NET Framework 4.8 or later, and a stable internet connection for downloading updates and executor binaries.

### Is XCutors free to use?

Yes, the loader and the bundled executors included in this collection are available free of charge.

### How do I update the executors?

Open xcutorsLoader and click the 'Check for Updates' button. The loader will automatically detect new versions and download them for you.

### Can I add my own Lua scripts?

Absolutely. You can import .lua files from your local drive using the 'Load Script' button, or paste code directly into the built-in editor.

### Why does my anticomponent flag the loader or executor?

Roblox executors use code injection techniques that are often flagged by anticomponent heuristics. You may need to add an exception for the XCutors folder in your anticomponent software. Only download from this official repository.

### Which Roblox versions are supported?

The executors are maintained to support the latest stable Roblox Windows client. After Roblox updates, executor compatibility patches are typically pushed within hours to days.

### Where can I find scripts to run?

XCutors includes a built-in script hub with curated community scripts. You can also find scripts on community forums and Discord servers dedicated to Roblox scripting.

### How do I report bugs or request features?

Open an issue on this GitHub repository with the 'bug' or 'enhancement' label. Include your Windows version, executor name, and steps to reproduce the problem.
